## ✨ Features

- 🏭 **Factory Method & Abstract Factory** — For creating different types of rooms and doors
- 🏗️ **Builder Pattern** — To construct complex maze configurations step-by-step
- 🧠 **Strategy Pattern** — For dynamic pathfinding and generation algorithms
- 🎮 **Visual Maze Generation** — Watch the design patterns in action

## 🚀 Quick Start

```bash
# Clone the repository
git clone git@github.com:Zishwhwhw/java-maze-design-patterns.git
cd java-maze-design-patterns
```

Compile and run using your preferred IDE (IntelliJ, Eclipse).
